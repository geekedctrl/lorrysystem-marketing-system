## Discovery model-output recovery

After the buyer-qualification release, a live DEV discovery batch found six sites but yielded no candidates: three model assessments failed as `MODEL_OUTPUT_INVALID`, while two sites could not be fetched. Regression tests cover JSON-mode request and one successful assessment correction. Local backend suite passes: 53 tests, one browser-only test skipped; Python compile and Git whitespace checks pass. No live provider call was made.
